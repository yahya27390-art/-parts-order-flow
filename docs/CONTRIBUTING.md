# قواعد المساهمة وسير العمل

## قبل أي دفعة (Push)

```bash
npm run check      # lint + test + build
```

الدفع إلى `main` يُشغّل النشر تلقائيًا إلى GitHub Pages، لذا لا تدفع كودًا لا يمرّ الفحص.

## قواعد إلزامية

1. **لا كتابة مباشرة على جداول المستندات من الصفحات.** استخدم دوال `features/*/api.js`
   (التي تستدعي RPC الذرّي).
2. **أي قاعدة حسابية تُكتب في `logic.js`** ومعها اختبار في `logic.test.js` — لا حسابات داخل JSX.
3. **توافق القواعد الثلاثة:** عند تغيير قاعدة عمل، حدّث:
   - دالة SQL في `supabase/migrations/`،
   - `src/features/<domain>/logic.js`،
   - المسار البديل في `api.js` إن وُجد،
   - ثم الاختبارات.
4. **لا رسائل خطأ إنجليزية للمستخدم.** استخدم `getErrorMessage` أو ارفع رمز خطأ معروفًا
   (انظر `docs/DATABASE.md` → رموز الأخطاء).
5. **الاستعلامات على الخادم**: استخدم `selectRows`/`countRows` مع `search`/`filters`/`page`
   ولا تنزّل جدولًا كاملًا إلى المتصفح.
6. **لا `console.log` للتشخيص**؛ استخدم `toast` للأخطاء المرئية و`console.error` عند الحاجة التقنية فقط.
7. **الألوان من توكنات التصميم**: `bg-brand`, `text-brand-accent`, ... بدل قيم hex مضمّنة في مكوّنات جديدة.

## نمط الكود

- مكوّنات دالة + hooks فقط، وواجهة عربية RTL.
- أسماء الملفات: `PascalCase.jsx` للمكوّنات، `camelCase.js` للأدوات.
- الاستيراد بالاسم المستعار `@/...`.
- تقسيم المكوّنات الكبيرة: أي صفحة تقترب من 300 سطر يُفصل منها المكوّنات/الحوارات
  (مثال: `components/items/ItemFormDialog.jsx`).

## إضافة صفحة جديدة

1. أنشئ الملف في `src/pages/`.
2. أضِفه إلى `src/pages.config.js` بالاستيراد الكسول (`lazy`).
3. أضِفه إلى `navigationGroups` في `src/Layout.jsx` (مع `adminOnly: true` إن كانت إدارية).

## إضافة عملية جديدة (مثال: إرجاع للمورد)

1. اكتب دالة SQL في ترحيل جديد تنفّذ العملية كاملة داخل معاملة واحدة + حركات `return_to_supplier`.
2. أضِف دالة في `features/<domain>/api.js` تستدعيها عبر `callRpc` بمسار بديل عند الحاجة.
3. أضِف hook في `hooks.js` مع إبطال مفاتيح الكاش المؤثرة (`items`, `inventory`, `orders`, `reports`).
4. أضِف الاختبارات في `logic.test.js`.
5. وثّق الدالة في `docs/DATABASE.md`.

## مراجعة الكود (Checklist)

- [ ] `npm run check` يمرّ بنجاح
- [ ] لا استعلامات مباشرة في الصفحات
- [ ] الحسابات في `logic.js` ومعها اختبار
- [ ] رسائل الأخطاء عربية ومفهومة
- [ ] لا كسر للتوافق مع القاعدة قبل تطبيق الترحيلات
- [ ] تحديث التوثيق عند تغيير السلوك
